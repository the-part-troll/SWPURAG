## 复现命令

在项目的 Anaconda `SWPU_RAG`（Python 3.12）中用 `pdfplumber 0.11.9`（见[依赖清单](../requirements-pdf.txt)）执行。离线重建只读归档文件和清单。模型评测沿用[已有凭据加载方法](admissions-evaluation.md)，`SWPURAG_MODEL=deepseek-flash`。复跑为输出选择未占用的文件名。

```powershell
Set-Location 'P:\SWPURAG'
$env:PYTHONIOENCODING = 'utf-8'
conda activate SWPU_RAG
python -B -m swpurag --db data/admissions-catalog-scope-check.sqlite3 import
python -B -m swpurag import --sample masters-full-time-directory-2027
python -B -m swpurag stats
python -B -m unittest discover -s tests -v
python -B -m swpurag.evaluate --generate --method natural --method scoped --questions samples/admissions-catalog-scope-eval.json --output reports/admissions-catalog-scope-comparison.jsonl
python -B -m swpurag.evaluate --generate --method scoped --only Q2 --only Q3 --output reports/admissions-catalog-scope-regression-q.jsonl
python -B -m swpurag.evaluate --generate --method scoped --questions samples/admissions-acceptance.json --only A1 --only A3 --only A5 --output reports/admissions-catalog-scope-regression-a.jsonl
```

隔离重建与正式库均为 8 篇文档、8 个版本、648 个块。18 项离线测试通过。19 条评测记录包括 18 次成功模型调用和 1 次直接澄清。58 处引文全部通过原件和文字复核，其中 39 处 PDF 引用可回查页、行和单元格。
