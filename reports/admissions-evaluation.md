## 运行方式

模型凭据从工作区已有配置载入当前 PowerShell 进程，服务地址使用 `https://api.deepseek.com`，模型为 `deepseek-flash`。进入工作区后执行以下命令。再次运行时为输出选择未占用的文件名。

```powershell
Set-Location 'P:\SWPURAG'
$env:PYTHONIOENCODING = 'utf-8'
$env:SWPURAG_BASE_URL = 'https://api.deepseek.com'
$env:SWPURAG_MODEL = 'deepseek-flash'
$entry = Get-Content -LiteralPath 'envir/.env' |
    Where-Object { $_ -match '^\s*DEEPSEEK_API_KEY\s*=' } |
    Select-Object -First 1
if (-not $entry) { throw 'Missing configured model key' }
$env:SWPURAG_API_KEY = ($entry -split '=', 2)[1].Trim().Trim([char[]]@(34,39))
python -B -m swpurag.evaluate --generate --output reports/admissions-evaluation-r2.jsonl
python -B -m unittest discover -s tests -v
```

评测命令退出码为 0。另运行的 8 项离线测试全部通过，覆盖旧档回放、较新同内容抓取推进观察时间、异常 HTTP 200 正文、去重、历史保留和回答引用校验。

## 判定与汇总

Top 5 按冻结文件的必要证据组计算，组内来源可替代，跨文档题需要各组均命中。Q5 缺具体分数线，Q6 需要先澄清角色，两题不计入覆盖分母。随表格或条款提供的表头和上级标题没有排名，可引用，但不计入 Top 5。

回答人工判定分为通过、部分正确和失败。通过要求覆盖问题核心、尊重原文适用对象与条件，或在证据不足、歧义时作相应处理。Q7 另记未提供的附带收费说明。引用回查按独立维度计数，复核了引文在当次证据中的文本、官网 URL、原件 SHA-256，以及原件的正文块、行列和选择器。

## 失败样例和原件复核

- **Q2，普通专科报考年限仍漏检。** 复测引用章程正文块 33、35，确实仅涉及工商管理、工程管理专业学位的特殊工作经验要求。普通规则见第十条（三）第 3 项，正文块 26，原件第 200 行第 24766 列。国家承认的高职（专科）学历毕业至录取当年入学前须满 2 年，按本科毕业同等学力报考。考点公告块 13、25 支持材料子问，其中块 13 明确限定在非应届考生的补充材料。复测将回答标为 `answered`，缺少普通年限的依据提示。[招生章程](https://www.swpu.edu.cn/gs/info/1073/8520.htm) · [5110 考点公告](https://www.swpu.edu.cn/gs/info/1074/8650.htm)
- **Q3，复测格式通过，选点规则仍有范围错误。** 首轮报错为“完整回答需要引证且不能附带缺口”，属于输出校验拒收。复测引用的 5110 公告正文块 24（第 200 行第 15760 列）列明了不同人群。应届本科毕业生原则上按就读地指定报考点选择，成人高校应届毕业生还可按教学点所在地选择。报考该校单独考试须选 5110。工作地或户籍地规则适用于其他考生，还须保留招生单位特殊要求的例外。复测将这条规则扩大为所有普通统考考生。[5110 考点公告](https://www.swpu.edu.cn/gs/info/1074/8650.htm) · [10615 招生单位公告](https://www.swpu.edu.cn/gs/info/1074/8660.htm)
- **Q7，主问题正确，正式收费说明仍缺。** 章程第二十五条表头在正文块 105（第 200 行第 94961 列），对应金额行在块 114（第 200 行第 115362 列）。非全日制列和 125601 行交叉处为 24,000，单位为元/年·生。表后的块 121 说明最终以学校正式文件为准，未进入该次模型证据。[招生章程](https://www.swpu.edu.cn/gs/info/1073/8520.htm)
