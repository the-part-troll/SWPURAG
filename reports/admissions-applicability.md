## 改动与运行

- 回答按原文的对象、触发条件和例外写结论，要求把决定适用范围的条件写入同一条主张并引用相应条款。原文的“其他”保留其排除前列分支后的范围。
- 多个明确子问各取一条候选，再按版本与正文块去重，以整问排名补足，总检索预算仍为 Top 5。问句里的“满多久”等表达保留阈值动词，便于与正文匹配。每个子问的模型输出单独校验，合并时先展示有据主张，再说明未答子问的缺口。
- 沿用已有的表头与条款标题上下文，单独标记为无排名证据。它们可引用，但不计入 Top 5。原关键词检索和单独的自然检索入口保持原有用法。本次模型回归和验收运行实际问答入口使用的自然检索。

在 PowerShell 进入 `P:\SWPURAG`，按[上轮配置](admissions-evaluation.md)载入已有凭据。模型为 `deepseek-flash`，输出命名需使用未占用文件。

```powershell
Set-Location 'P:\SWPURAG'
$env:PYTHONIOENCODING = 'utf-8'
$env:SWPURAG_BASE_URL = 'https://api.deepseek.com'
$env:SWPURAG_MODEL = 'deepseek-flash'
python -B -m swpurag.compare --output reports/admissions-r3-fixed.jsonl
python -B -m swpurag.compare --structured-partial --output reports/admissions-r3-partial.jsonl
python -B -m swpurag.evaluate --generate --method natural --output reports/admissions-r3-regression.jsonl
python -B -m swpurag.evaluate --generate --method natural --questions samples/admissions-acceptance.json --output reports/admissions-r3-acceptance.jsonl
python -B -m unittest discover -s tests -v
```

17 次模型调用全部返回并通过输出校验，9 项离线测试通过。重读归档原件并校验 SHA-256、正文块、定位和引文，4 个新结果文件的 47 处引用全部可回查。人工核验与格式、引用核验分别计分。
