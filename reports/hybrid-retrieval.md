# 首轮混合检索对照

2026-11-13。在浏览器默认的 `scoped` 路由、范围过滤和共享 Top 5 下，仅对比证据排序。使用现有 13 篇文档、747 个正文块；未请求回答模型，浏览器默认仍为词法。结论：RRF 改善了个别问题并过滤了一次标注的错范围混入，但也挤掉了另一题的必要材料，总体没有提高找齐率。

## 口径与复现

先核对原件并冻结 [H01–H10 招生题](../samples/hybrid-admissions.json) 和 [H11–H21 图书馆与跨主题题](../samples/hybrid-library-mixed.json)，共 21 道新问句。文件按 LF 计算的 SHA-256 固定在评测脚本中。每个必要证据组允许已标注的等价段落或页行；有一个组命中即算任一，所有组命中才算找齐。澄清和缺证据的 6 题不计召回分母。错范围统计为命中预先标注的不适用位置或错误主题，不代表核尽了所有无关结果。表头等自动附加上下文不计 Top 5，但单列其影响。

- **词法**：使用浏览器当前的 BM25 及其现有词项约束、图书馆无词法匹配时的候选回退。
- **向量**：使用 [shibing624/text2vec-base-chinese 模型卡](https://huggingface.co/shibing624/text2vec-base-chinese)，快照 `183bb99aa7af74355fb58d16edf8c13ae7c5433e`，正文和问句分别编码。按模型配置截断至 128 token、对有效 token 做均值池化并归一化，保留 768 维 float32 向量，按余弦相似度降序。长段落只参与前 128 token 的向量表示。
- **融合**：在运行新题前固定等权 RRF，`k=60`，每个批次两路最多各取 20 条，按 `Σ 1/(60 + rank)` 排序，某一路未入榜则该路不计分。并列先比最好单路名次，再比词法名次和正文块编号。最终仍由原有主题轮取和子问预留逻辑合并到 Top 5。

同一问句三路的主题、子问批次和候选列表逐批校验一致，库中原始正文位置不由排名器改写。记录中的候选数是各批次的去重并集，单批候选数亦保留；候选为 0 意味未进入排序。延迟为预热后每题一次，从路由到证据与上下文返回，包含本地问句编码和数据库读取，排除模型/索引加载、评分与写文件；轮换三种方法的执行顺序。单候选的向量排序无需编码。百分位按最近秩计算。

环境：Windows、Anaconda `SWPU_RAG`（Python 3.12.16），PyTorch `2.8.0+cpu`（4 线程）、Transformers `4.57.6`、NumPy `1.26.4`、tokenizers `0.22.2`、safetensors `0.8.0`。本次使用本机已存在的模型快照。新机器可在联网阶段从[固定版本的文件清单](https://huggingface.co/shibing624/text2vec-base-chinese/tree/183bb99aa7af74355fb58d16edf8c13ae7c5433e)获取所需文件；构建和评测均离线。

```powershell
Set-Location 'P:\SWPURAG'
conda activate SWPU_RAG
$env:PYTHONIOENCODING = 'utf-8'
python -B -m pip install --target data/local/hybrid-torch --index-url https://download.pytorch.org/whl/cpu 'torch==2.8.0+cpu'
python -B -m pip install --target data/local/hybrid-transformers --index-url https://pypi.org/simple -r requirements-hybrid.txt
$env:PYTHONPATH = "$(Join-Path $PWD 'data/local/hybrid-torch');$(Join-Path $PWD 'data/local/hybrid-transformers')"
$model = Join-Path $env:USERPROFILE '.cache\huggingface\hub\models--shibing624--text2vec-base-chinese\snapshots\183bb99aa7af74355fb58d16edf8c13ae7c5433e'
# 无模型快照时，联网下载到项目忽略目录，取代上面的 $model。
if (-not (Test-Path (Join-Path $model 'model.safetensors'))) {
  $model = 'data/local/183bb99aa7af74355fb58d16edf8c13ae7c5433e'
  python -B -c "from huggingface_hub import snapshot_download; import sys; snapshot_download('shibing624/text2vec-base-chinese', revision='183bb99aa7af74355fb58d16edf8c13ae7c5433e', local_dir=sys.argv[1], allow_patterns=['model.safetensors', '*.json', 'vocab.txt'])" $model
}
$env:HF_HUB_OFFLINE = '1'
# 无现成 SQLite 时，从随库公开原件重建。
python -B -m swpurag import
python -B -m swpurag.hybrid_eval build --model-dir $model --index data/local/hybrid-text2vec-r1.npz
python -B -m swpurag.hybrid_eval evaluate --model-dir $model --index data/local/hybrid-text2vec-r1.npz --output reports/hybrid-retrieval-repeat.jsonl
```

已有库与索引时可跳过对应重建。索引与结果文件采用独占创建，重跑时用新文件名。依赖和索引位于已忽略的 `data/local/`。本次运行的权重 SHA-256 为 `0c855515479137398ce4ea985628548d4e8ed8c5764656dac966d6a24f39e721`，索引语料签名为 `0a2e8d0d44175acad0fa0940e15d9c1ded0cdfa2cd8ca19abc7c7de8e564dcb8`。原有 31 项离线测试通过；32 道旧题的默认词法完整结果与修改前逐项一致。逐题排名共使用 131 个不同正文块，全部按归档哈希重新解析核对成功。

## 旧题回归与结论边界

原 Q、A、D、F、L 各集的 32 题按既有标注重放。24 道标为可答的题，词法、向量、RRF 的任一命中均为 24/24，找齐分别为 **24/24、22/24、24/24**，无已标注的错范围混入。向量在 A3 漏掉章程第 36 段「125601 仅能报考非全日制定向」的条件，在 F7 漏掉章程第 26 段的普通专科年限；RRF 均保留。Q2、Q3、A1、F3 的必要证据三路均找齐；F4 三路都识别到澄清，A5 的可用背景三路均命中，但缺少的部分本轮没有通过生成判断。D1、D2、D4 是旧单目录语料的口径：D1、D2 旧必要证据三路都找到，D2 现已触发学习方式澄清；D4 的旧非全日制证据被当前全日制范围排除，三路均找到全日制目录第 6 页第 22 行，不作退化判断。Q6 的招生单位与报考点澄清原依赖生成；仅靠本轮前置规则未标为澄清。

当前规模只支持判断这组冻结题、这一个中文模型和这套固定融合参数。多个图书馆题在范围确定后没有可比较的排序空间；跨主题的主要漏检来自路由和服务、日期识别。复审建议先处理 H11、H19–H21，并保留其原题原标注复测；若继续实验，再增加过滤后确实仍有多个可竞争证据的冻结题。本轮不切换浏览器的默认检索。
